PROOF: the packed tarball installs into a clean Expo project and all six mods run

The README says "Tested against Expo SDK 50". Two projects were built from scratch:

  Expo SDK 57.0.8 — prebuild FAILS, on master and on chore/magic-tooling alike:
  "Cannot find a suitable place to insert the CodePush buildscript dependency".
  SDK 57's android/app/build.gradle carries no `apply from:` line at all, so none
  of the four anchors the plugin searches for exists. Pre-existing upstream drift,
  identical before and after, not this PR's to fix.

  Expo SDK 50.0.21 — prebuild SUCCEEDS. Both tarballs were built with `npm pack`,
  installed from a file: path into the same project, and prebuilt with
  `npx expo prebuild --clean`. Results below.
